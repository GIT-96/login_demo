# GIT Credit Tracker v1.0.3
A privacy-first offline credit and debt tracker for Android. Start with an EMPTY ledger; no customer account information is committed to this public repository. Fill in your own debts and credit score privately on the device.
Build via GitHub Actions and download the APK artifact (ZIP) from the successful workflow run.
This build is signed with the default Android debug keystore if configured as Flutter's default release template. It is for testing, not Play Store distribution.
